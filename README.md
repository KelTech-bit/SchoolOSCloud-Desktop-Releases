# SchoolOSCloud Desktop Releases

Official public Windows installer releases for [SchoolOSCloud](https://schoolosc.org).

## Download

Download the latest verified build from the [SchoolOSCloud download page](https://schoolosc.org/download) or from [GitHub Releases](https://github.com/KelTech-bit/SchoolOSCloud-Desktop-Releases/releases/latest).

- Windows 10 or Windows 11 (64-bit)
- Offline-first local school setup and administration
- Installer binaries are distributed through GitHub Releases, not the Vercel web deployment

> The initial 0.1.0 installer is not code-signed. Windows SmartScreen may display an unrecognized publisher notice.

This repository is for public release binaries only. The SchoolOSCloud application source remains in its private repository.
